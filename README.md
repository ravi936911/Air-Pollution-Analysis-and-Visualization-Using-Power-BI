# Air Pollution Analysis and Visualization Using Power BI

This project focuses on analyzing and visualizing air pollution data using **Power BI** to gain meaningful insights into environmental conditions and pollution trends. The dataset includes important air quality parameters such as **PM2.5, PM10, NO2, SO2, CO, Ozone**, along with location and time-based records.

Using Power BI, interactive dashboards were created to monitor pollution levels across different regions, compare pollutant concentrations, and identify patterns over time. Various charts, maps, KPI cards, filters, and slicers were used to make the data easy to understand and explore.

The project helps in understanding how air quality changes by city, state, and time period, enabling better decision-making for environmental awareness and pollution control measures. It demonstrates the practical use of **Business Intelligence tools** for transforming raw environmental data into clear, actionable insights.

### Key Features:

* Interactive dashboards for air pollution monitoring
* Region-wise and time-wise pollution analysis
* Comparison of multiple pollutants
* Trend analysis using charts and graphs
* User-friendly filters and slicers
* Clean and visually appealing reports

### Tools & Technologies Used:

* Microsoft Power BI
* Microsoft Excel / CSV Dataset
* Data Cleaning & Transformation
* Data Visualization Techniques

### Outcome:

This project showcases how Power BI can be used to analyze environmental datasets efficiently and present valuable insights through modern dashboards.
